# elitopolis-podbor

Статическая посадочная страница АН «Элитополис» для лидов из Shorts.

## Важно
- На GitHub нет названия внутреннего объекта.
- Страница отправляет только код кампании `troitsky_01`.
- Внутреннее сопоставление `troitsky_01 -> Фонтанка 130` будет находиться в n8n на российском сервере.
- Рабочая страница использует обработчик формы и production webhook, заданные в `index.html`. Старые `config.js` и `app.js` этой страницей не подключаются.

## GitHub Pages
После загрузки файлов:
Settings -> Pages -> Build and deployment -> Deploy from a branch
Branch: `main`
Folder: `/ (root)`


## Яндекс Метрика

Счётчик `113665495` загружается из `analytics.js` после согласия посетителя. Выбор можно изменить кнопкой «Настройки аналитики». До согласия или после отказа сторонний код не загружается. Вебвизор и передача значений полей формы отключены. Статистика охватывает посетителей, разрешивших аналитику.

Создайте в интерфейсе счётчика цели типа «Целевое событие» (JavaScript-событие):

| Идентификатор | Значение |
| --- | --- |
| `form_view` | Форма появилась на экране |
| `lead_submit` | Валидная заявка отправляется на сервер |
| `lead_success` | Сервер ответил HTTP 2xx; это не независимое подтверждение записи в базе |
| `lead_error` | Сетевая ошибка или ответ HTTP с ошибкой |
| `phone_click` | Нажатие на телефон; это не подтверждённый звонок |

Первый контрольный лид проверяется также по строке в Leads и письму. Значения контактов в цели Метрики не передаются. Источник и UTM-кампания сохраняются в действующей форме.

Проверки без внешних запросов: `node --test tests/analytics.test.cjs`.
